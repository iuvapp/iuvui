# @iuvui/utils

Shared class-name and typed variant utilities for iuvui.

```ts
import { cn } from "@iuvui/utils";
import { createVariants } from "@iuvui/utils/variants";

const className = cn("rounded-md px-3", "px-4");
```

The package is framework-light and publishes ESM entry points with TypeScript
declarations.

See the [iuvui repository](https://github.com/iuvapp/iuvui) for documentation
and source.
