The iuvui Registry uses shadcn-compatible item JSON with an iuvui metadata
extension for semantic version, integrity, canonical source, immutable upstream
references, license, relationship, and local deviations.

## Public Registry artifacts

The public Registry catalog generated by the current source tree contains
Button, Card, Input, Label, Separator, and Textarea. Those are the source
artifacts linked from the public documentation. A live `iuvui.com` response is
asserted only after a separate deployment and external verification. npm
publication is a separate step and is not implied by these generated files.

- [Button Registry JSON](/r/button.json)
- [Card Registry JSON](/r/card.json)
- [Input Registry JSON](/r/input.json)
- [Label Registry JSON](/r/label.json)
- [Separator Registry JSON](/r/separator.json)
- [Textarea Registry JSON](/r/textarea.json)

Text Field and Dialog remain package-only: they have canonical package exports
and styles, but no source Registry item yet.

The last public npm release remains `0.0.1` and does not include Card, Input,
Label, or Textarea CSS. Installing those Registry items against npm `0.0.1`
cannot pick up the matching styles until a later authorized `0.0.x` package
publication.
