The iuvui Registry uses shadcn-compatible item JSON with an iuvui metadata
extension for semantic version, integrity, canonical source, immutable upstream
references, license, relationship, and local deviations.

## Released Registry

The public Registry catalog generated by the current source tree contains Button
and Separator at `0.0.1`. Those are the only source artifacts linked from the
public documentation. A live `iuvui.com` response is asserted only after a
separate deployment and external verification.

- [Button Registry JSON](/r/button.json)
- [Separator Registry JSON](/r/separator.json)

## Local staging

Card, Input, Label, and Textarea have generated source and provenance artifacts
for local verification, including packed package and CSS entry points. They
stay in the repository's local staging Registry until a fresh allowed `0.0.x`
package release is authorized. They are excluded from the public Registry catalog
so a user cannot accidentally install an item whose matching
`@iuvui/styles@0.0.1` CSS has not been released.

This separation lets package mode, source mode, notices, integrity, and
upstream traceability be tested together without treating a local artifact as a
public release.
