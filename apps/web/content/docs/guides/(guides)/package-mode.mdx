---
title: Package mode
description: Install the maintained public component package and its precompiled styles.
---

The last public package release is `0.0.1`.

```bash
pnpm add @iuvui/react @iuvui/styles
```

Import the complete style bundle once:

```css
@import "@iuvui/styles";
```

The last public npm React exports are Button, Text Field, Dialog, and
Separator. The canonical workspace package now also exports Card, Input,
Label, and Textarea, with matching `@iuvui/styles` entry points, on the same
path as those foundation components.

## Next `0.0.x` publication

Card, Input, Label, and Textarea are first-class package and Registry artifacts
in this repository. They cannot be added to the already-published npm `0.0.1`
artifacts. A later explicitly authorized `0.0.x` release must complete package,
Registry, and independent-consumer checks before npm consumers can install them.
