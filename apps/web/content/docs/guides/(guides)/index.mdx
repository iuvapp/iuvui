title: Guides
description: How the current iuvui package, source, and Registry surfaces relate to one another.
---

iuvui is designed to support maintained package delivery and owned source
delivery without presenting planned work as a release. These guides distinguish
what is publicly available today from what is verified in the repository.

- [Package mode](/docs/guides/package-mode) covers the public npm surface.
- [Source delivery](/docs/guides/source-delivery) describes the locally verified
  CLI behavior and the future public command shape.
- [Registry](/docs/guides/registry) explains the released Registry and the
  local staging boundary.
