iuvui is an ownable React UI system. It pairs maintained packages with an
owned-source workflow, so a team can choose the level of implementation it
wants to maintain. The public website, documentation, catalog, and Registry
all live in the same TanStack Start application. There is no separate
documentation application or Cloudflare Worker.

Every component is free, including complex components. Package mode and source
mode are two delivery forms of the same component contract; neither changes
the accessibility or behavioral baseline.

## Choose a delivery mode

### Package mode

The public `0.0.1` package release contains Button, Text Field, Dialog, and
Separator. Install the maintained React package and its precompiled styles:

```bash
pnpm add @iuvui/react @iuvui/styles
```

Card, Input, Label, and Textarea are workspace previews in this repository.
Their package exports and CSS are verified locally, but they are not npm
releases and must not be installed from `@iuvui/react@0.0.1` or
`@iuvui/styles@0.0.1` yet.

### Source mode

The CLI installs owned component source under `components/iuv-ui`. Its source
workflow has been verified locally with a packed tarball, but `@iuvui/cli` is
not yet published to npm. Public `pnpm dlx` and global-install commands remain
unavailable until an explicitly authorized release.
