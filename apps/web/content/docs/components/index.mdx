Every component is free, including complex components. iuvui is designed to
offer package mode and owned-source mode from the same canonical implementation;
current delivery availability is stated per component below.

This catalog includes published exports and workspace previews. A workspace
preview can be explored from this repository, but is not yet an npm release or
a publicly consumable Registry item. Component cards state package and source
availability separately.
