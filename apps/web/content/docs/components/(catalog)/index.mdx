Every component is free, including complex components. iuvui is designed to
offer package mode and owned-source mode from the same canonical implementation;
each component page states the delivery availability that exists today.

## Delivery states

**Published** means the component is on the canonical `@iuvui/react` package
path in this repository, with matching styles and, when a source item exists,
public Registry JSON. **Package only** means the canonical component package
includes the component, but there is not yet a matching source Registry item.
The last public npm release remains `0.0.1` and does not include Card, Input,
Label, or Textarea until a later authorized `0.0.x` publication.

| Component  | Package delivery | Source delivery         | Documentation                             |
| ---------- | ---------------- | ----------------------- | ----------------------------------------- |
| Button     | Published        | Published Registry item | [Button](/docs/components/button)         |
| Text Field | Published        | Package only            | [Text Field](/docs/components/text-field) |
| Dialog     | Published        | Package only            | [Dialog](/docs/components/dialog)         |
| Separator  | Published        | Published Registry item | [Separator](/docs/components/separator)   |
| Card       | Published        | Published Registry item | [Card](/docs/components/card)             |
| Input      | Published        | Published Registry item | [Input](/docs/components/input)           |
| Label      | Published        | Published Registry item | [Label](/docs/components/label)           |
| Textarea   | Published        | Published Registry item | [Textarea](/docs/components/textarea)     |

Public Registry JSON is generated for Button, Card, Input, Label, Separator,
and Textarea. Text Field and Dialog remain package-only. npm publication is a
separate step and is not implied by this catalog.

## Variants and customization

Component variants live with each component contract. The current Button API
has an interactive matrix for its free variants, sizes, and radii. Use the
[Variants](/docs/components/variants) page to inspect that contract and the
public customization boundary.
