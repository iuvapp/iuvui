iuvui is a React UI system with two delivery modes backed by the same canonical component implementation.

## Package mode

Install the maintained React package and its precompiled styles:

```bash
pnpm add @iuvui/react @iuvui/styles
```

## Source mode

The public CLI installs owned component source under `components/iuv-ui`. The CLI package is not yet published, so the public source-mode command remains unavailable until an explicitly authorized release.
